# DbRelay soak test: Oracle

**Result: PASS** (9/9 invariants)

**Environment:** GitHub Actions `ubuntu-latest`. Oracle Database 23ai Free (`gvenzl/oracle-free:23-slim-faststart`) in a service
container on the same runner. Workflow run 45883820051, commit `536f4d3` (branch `oracle-provider`, all Oracle review fixes
OR-01..OR-13). The 1,000-record storage-interface limit added later (`19bdf8c`) is not exercised by the soak. The job limit is 6
hours, so the load phase is 5 h 20 min.

**Memory:** the long-lived worker w0 rose during warm-up (133 MB at 30 s, 193 MB at 20 min), then stayed between 174 and 197 MB for
the remaining five hours while 33,000 more messages flowed: a plateau, not growth. Threads (21-26) and handles (192-203) stayed flat.
